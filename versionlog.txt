Version 1.0 — Initial Release

Navigation & Views
- Tab-based navigation with 5 views: Form, Calendar, Pending Jobs, Past Jobs, Export
- Role-based access: Admin sees all views, Driver sees Calendar only, public sees Form
- Responsive layout for desktop and mobile

Transport Request Form
- Contact information (email, name, telephone)
- Department mode with cost centre search (autocomplete from 125 codes)
- Student mode with student ID and auto-generated analysis code
- Trip details (recipient, passengers, luggage with quantity selector)
- Service type selection (one-way / round trip)
- Pickup location with preset suggestions (USC Gym, Airport, Residence Halls)
- Conditional flight number field (when pickup is Piarco Airport)
- Dropoff location and return trip fields (for round trips)
- Form validation and success/error status banners
- Submission persists to Firestore

Calendar
- Year-at-a-glance with all 12 months in a responsive grid
- Colour-coded driver dots on each day (Brent, Vincent, Tauren, Other)
- Today highlighting and selected-day state
- Year navigation with chevron buttons
- Day detail modal — lists all trips for the selected day
- Trip detail modal — full trip information display
- Real-time updates via Firestore snapshot listener

Pending Jobs
- Real-time list of all requests sorted by creation date
- Status filter bar: All, Pending, Approved, Cancelled (toggle on/off)
- Colour-coded status badges and dots
- Pagination (20 per page)
- Job detail view with edit mode
- Editable fields: name, pickup/dropoff, dates, times, flight, recipient, passengers, luggage, service type, driver, status
- Driver autocomplete suggestions
- Delete with confirmation modal

Past Jobs
- Completed jobs list grouped by month with month headers
- Search by name, last name, or account name
- Sort toggle: newest first / oldest first
- Pagination (15 per page)
- Job detail view with read-only grid
- Edit mode for trip details (pencil toggle)
- Driver assignment with autocomplete (Brent, Vincent, Tauren)
- Administrator section: amount, currency toggle (TTD/USD), account code
- Delete with confirmation modal

Export Reports
- Date range selection with start/end date pickers
- Preset ranges: This month (25th–25th), Last month (25th–25th), Last 7 days, This year
- Trip count and total amount preview
- One-click Excel workbook generation via SheetJS
- Sheet columns: Date, Acct Code, Account Name, Fund (10), Function, Transaction Description, Amount, Currency
- Merged title header: "TRANSPORTATION REPORT - {Month Year}"
- Currency formatting on amount column

Authentication
- Firebase email/password authentication
- Admin and Driver role buttons with pre-filled emails
- Inline login dropdown with password field
- Persistent session via onAuthStateChanged
- Logout with automatic view reset

Design & UX
- Custom colour palette with semantic tokens
- Fraunces display font and Instrument Sans body font
- Fade-in page transitions
- Hover effects and interactive states
- Modal overlays with backdrop blur
- Responsive breakpoints at 1024px, 640px, and 480px
- Keyboard-navigable autocomplete dropdowns

Infrastructure
- Firebase Firestore database (Requests collection)
- Vite build toolchain with React 19
- Cloudflare Pages deployment via Wrangler
- 125 cost centres pre-loaded from university data
- SVG favicon set for PWA support
